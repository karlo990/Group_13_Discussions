Every exam program is 6 steps

Mnemonic: Happy Ducks In Ponds Only Relax. Examiners give marks for each step, so even half a program scores if the steps are visible.

HHeader comment + #include
DDeclare variables with types and start values
IInput: prompt, then scanf with &
PProcess: if-ladder, loop or formula
OOutput: printf with labels and units
Rreturn 0;

The skeleton

/* H: what this program does */
#include <stdio.h>

int main(void)
{
    double x, result;          /* D */
    printf("Enter x: ");       /* I */
    scanf("%lf", &x);
    result = x * x;            /* P */
    printf("x^2 = %.2f\n", result); /* O */
    return 0;                  /* R */
}

int fib(int n)
{
    if (n <= 1) return n;   /* base case */
    return fib(n - 1) + fib(n - 2);
}

3 · Tiered rate ladder (ZESA, PAYE)

if (u <= 200)      e = u * 0.80;
else if (u <= 300) e = 160 + (u - 200) * 0.90;
else               e = 250 + (u - 300) * 1.00;
total = e + 10;                   /* meter charge */

4 · Menu loop (ATM, calculator)

do {
    printf("1 Deposit 2 Withdraw 3 Balance 4 Exit: ");
    scanf("%d", &choice);
    switch (choice) {
    case 1: ... break;
    case 2: if (amt > bal) printf("Insufficient\n");
            else bal -= amt;  break;
    default: printf("Invalid\n");
    }
} while (choice != 4);

check before you subtract

5 · Pass by reference (swap)

void swap(int *a, int *b)
{ int t = *a; *a = *b; *b = t; }

swap(&x, &y);   /* send the addresses */

value = photocopy, reference = the original

6 · Factorial (loop)

unsigned long long fact = 1;
for (i = n; i >= 1; i--)
    fact = fact * i;
printf("%d! = %llu\n", n, fact);

for (i = len - 1; i >= 0; i--)

8 · Copy a file (F-O-R-C)

FILE *src = fopen(a, "rb"), *dst = fopen(b, "wb");
if (src == NULL || dst == NULL) return 1;
int ch;                 /* int, so EOF fits */
while ((ch = fgetc(src)) != EOF)
    fputc(ch, dst);
fclose(src); fclose(dst);

Number bases, by hand and by checker

No calculators in the exam, so learn the method; use this page to check your working. The rule of thumb: hex digit = 4 bits, octal digit = 3 bits.

Converter

Hex arithmetic checker

Past papers: BAE + DAD in octal; CAD × B0D in hex

Decimal → binary

Divide by 2, keep remainders, read upwards. Fractions: multiply by 2, keep the whole part, read downwards.

Binary → hex / octal

Group from the right in 4s (hex) or 3s (octal). Pad the left with 0s.

BCD

Each decimal digit on its own in 4 bits. 185 → 0001 1000 0101. Not the same as pure binary 10111001.

Red-pen traps: where marks disappear

Integer division

c = 5/9*(f-32); → always 0

c = 5.0/9.0*(f-32);

Average loses decimals

avg = sum / n;

avg = (double)sum / n;

Missing & in scanf

scanf("%d", &n);

= is not ==

if (choice == 2)

Wrong format code

%d int · %f print double · %lf scan double

char for EOF

char ch = fgetc(fp);

int ch = fgetc(fp);

switch without break

case 1: ... case 2: ... falls through

case 1: ...; break;

Never-ending while

while (n <= 100) sum += n*n;

{ sum += n*n; n++; }
